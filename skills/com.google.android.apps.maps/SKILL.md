# Maps

## Structure

- A map with a search field at the top and a bottom sheet that grows as you select a place.
  Directions open a route card with mode tabs (drive, transit, walk) and a Start button.
- The bottom sheet is draggable and hides content when collapsed; scroll it rather than
  concluding a detail is missing.

## Traps

- Search returns several places with the same name. Distinguish by the address line, not
  the name alone.
- "Start" begins turn-by-turn navigation, which takes over the screen with voice guidance
  and keeps the display awake. Getting out of it is not a single back press.
- Location permission and GPS state change what is possible; a missing "your location" is a
  device state, not a failed selector.

## Safety

- Read routes, times and addresses freely. Do not start navigation unless asked -- it is
  disruptive to whoever is holding the phone.
