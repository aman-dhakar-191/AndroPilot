# Telegram

## Structure

- A chat list over folders/tabs, each chat opening to messages with an input row. Search is
  global and matches chats, channels, and message text.

## Traps

- Channels, groups, bots and people all appear in the same list and look alike. A "channel"
  is usually read-only; a bot responds to commands. Check what kind of chat you are in
  before expecting to be able to send.
- Saved Messages is a chat with yourself and is easy to confuse with a contact.
- The input row's rightmost control changes between a microphone and a send arrow depending
  on whether text is present. Target it only after confirming text is in the field.

## Safety

- Sending, joining channels, and forwarding are all visible to other people. Compose and
  stop.
