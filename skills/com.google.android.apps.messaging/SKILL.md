# Messages (SMS/RCS)

## Structure

- A conversation list, each opening a thread with a text field and a send control at the
  bottom. New message starts with a recipient field.
- The send control is frequently an unlabelled icon; identify it by role and its position
  at the end of the input row.

## Traps

- The recipient must be committed from the suggestion list, not left as typed text.
- Long threads open scrolled to the bottom; older messages need scrolling up.
- A one-time code arriving in a thread is sensitive. Do not read it out or forward it.

## Safety

- Sending a message is irreversible and comes from the user's number. Compose and stop for
  approval unless sending was the explicit goal.
